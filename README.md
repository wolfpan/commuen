# Elegant Communication (优雅沟通)

**“我们不做翻译，只是帮助你更专业、优雅地表达想法。”**

「优雅沟通」是一个轻量级、支持私有化部署的 AI 文本重构引擎。它超越了传统机器翻译的局限，专注于跨文化职场与商业语境中的“心理学表达”，通过调用大语言模型（GLM、Qwen、DeepSeek），将用户的原始想法重塑为高度地道、专业且毫无“机器味”的目标文本。

---

## 理念：语境重塑而非机械翻译 (Philosophy)

沟通的本质并非词汇的对等替换，而是信息架构的重组与接收者心理预期的管理。本项目抛弃了“字对字”的直译逻辑，将文本重构建立在以下三个核心场景的专业准则之上：

* **内部协作 (Internal - Constructive Firmness):** 聚焦高效率与边界感。摒弃弱势的兜圈子表达，采用“客观现状+明确下一步”的建设性直率，使用跨国科技企业的高频原生惯用语，对事不对人。
* **商业公关 (Business/PR - Asynchronous Courtesy):** 追求高级感与平视视角的建立。打破机械断句，注重句流的呼吸感；将指令性的要求转化为异步沟通中的低压体贴，呈现从容的商业质感。
* **日常社交 (Social - Human Touch):** 强化真实人感。剥离说教味与官方腔调，以极简的口语化表达拉近人际距离，提供有效的情绪价值。

## 项目概况 (Overview)

本项目采用轻量级的全栈架构，非常适合部署在个人 VPS 环境中进行日常自我迭代与高频工作流处理。

* **极简视觉架构:** 前端遵循高对比度、暗黑极简主义（Dark Mode）设计理念。去除了所有视觉噪音，提供原生应用级（Native App Feel）的沉浸式输入体验。
* **统一模型网关:** 后端基于 Node.js / Express，原生兼容 OpenAI 接口规范，一键接入 GLM-4-Flash、Qwen-3.6-Plus 及 DeepSeek-V4-Flash 等主流高效模型。
* **私密与安全:** 舍弃了复杂的账户系统，采用轻量且高效的 PIN 码硬性鉴权拦截，保障个人自部署环境下的接口防盗刷与数据隐私。

## 核心作用 (Features)

1. **场景化文案生成:** 输入任意语言的草稿，系统依据设定的场景（内部、商业、社交）及目标语言（中文、英文），输出可直接用于全球化办公或公关发布的最终文案。
2. **决策思维可视化:** 在输出最终文案的同时，提供一句极简的 `Rationale`（重构逻辑），帮助用户理解此次重构如何优化了句流或心理体验。
3. **无缝工作流设计:** 深度集成剪贴板权限，支持一键粘贴输入与一键复制输出。复制成功提供视觉反馈，极大缩短工具切换的时间成本。
4. **响应式全屏体验:** 从桌面端的多面板对比，到移动端的单手持握流式操作，UI 层做了深度的响应式适配，确保在任何设备上均保持一致的优雅质感。

## 安装方式 (Installation)

系统依赖 Node.js 环境，整体部署极为轻量，可无缝接入现有的 Docker 或自托管（Self-hosted）技术栈。

**1. 克隆项目\安装依赖\系统初始化**

```bash
git clone git@github.com:wolfpan/commuen.git
cd commuen
npm install express axios dotenv
npm init -y

```

**2. 配置环境变量**

在项目根目录下创建 `.env` 文件，并填入相应的 API 密钥。为保障安全性，建议在公网部署时务必修改默认 PIN 码。

```env
# 安全鉴权
ACCESS_PIN=您的PIN码 (例如: 123456)
PORT=3001

# 模型 API 密钥配置
GLM_API_KEY=你的_智谱_API_KEY
ALI_API_KEY=你的_阿里云百炼_API_KEY
# DEEPSEEK_API_KEY=你的_DeepSeek_API_KEY (如需直连 DeepSeek 官方接口)

```

**3. 启动服务**

```bash
node server.js

```

服务默认运行在 `http://localhost:3001`。建议在生产环境中使用 `PM2` 守护进程，或将其打包进 Docker 容器结合 Nginx 反向代理与 HTTPS 证书对外提供服务。

## 使用方式 (Usage)

1. **鉴权访问:** 首次访问页面时，系统将被锁定。输入在 `.env` 中配置的 `ACCESS_PIN` 解锁系统（浏览器会本地记忆该状态）。
2. **输入与设定:**
* 在左侧面板输入或一键粘贴你需要重构的原始想法（哪怕是中英文夹杂的破碎短句）。
* 在底部面板选择**场景**（内部协作 / 商业沟通 / 日常社交）。
* 在右侧面板选择**输出语言**（中文 / 英文）。


3. **一键重构:** 点击“重构”按钮或使用快捷键 `Cmd/Ctrl + Enter`。
4. **查收与采纳:** 右侧面板将实时渲染经 AI 引擎重写后的高密度专业文案及重构逻辑。点击金色的复制图标，即可将最终文案应用到你的邮件、Slack 或公关稿件中。
